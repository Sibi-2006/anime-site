📺 Anime Explorer
Anime Explorer is a React-based web app that allows users to explore anime titles using the Jikan API. You can search, browse, and view detailed information about your favorite anime.

🚀 Features
🔍 Search Anime by name

🖼️ Display Posters, Titles, and Short Info

📄 Detailed Anime Pages (description, episodes, score, etc.)

🌙 Responsive and user-friendly UI

📦 Built using ReactJS

🔗 API powered by Jikan (MyAnimeList unofficial)

🛠️ Tech Stack
Frontend: ReactJS, HTML, CSS, JavaScript

API: Jikan API

Icons/Styling: Custom CSS, optionally FontAwesome or Tailwind
